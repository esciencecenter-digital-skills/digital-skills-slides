There is a number of tools that are used in conjunction for software development on this project and you need to set them all up on your machine and get used to using them all interchangeably as you would in a real-life team development setting. For the purpose of this course, we selected a number of free and open source tools that we believe make a difference: - **Command line tools** to run the code, install dependencies and set up a virtual development environment. - **PyCharm IDE** - a rich software development environment for developing, testing and debugging code. - **Git** to version control our code and GitHub to share it with the team and manage issues, communications and our software as a project. These tools are certainly not mandated in practice - you will often in practice have a choice of different similar tools - however for the purpose of this course we had to make a choice and hope that the knowledge you pick on here is transferable to other similar tools you may use in future.
